# GOLDEN VAULT — Online Starter (فارسی)

این مخزن **نسخه اولیه توسعه** است؛ هنوز محصول آماده مسابقه واقعی نیست.

## آنچه پیاده‌سازی شده
- رابط فارسی راست‌به‌چپ، ورود مستقل کاربران با Supabase Auth
- نمایش نقش خصوصی هر کاربر، نقشه کلیدهای اختصاصی تیم و موجودی تیم
- شروع هفته توسط مدیر و تقسیم تصادفی پنج نقش در هر تیم
- ثبت فروش هر ده نفر توسط مدیر و محاسبه سکه پایه، تارگت و تاپ‌سلر یکتا
- خرید کلید ۵۰ سکه و حذف تصادفی یک کلید قطعاً اشتباه با ۳۰ سکه؛ خریدها فقط برای فرمانده، با تابع تراکنشی در دیتابیس
- ثبت درخواست قدرت‌ها و اعلام عمومی فرمان حمله (بدون افشای هویت فرمانده)

## کارهای باقی‌مانده قبل از استفاده واقعی
**مهم:** عملیات سرقت، قتل، محافظت، جاسوسی، فرمان حمله و تسویه روز بعد هنوز به موتور پردازش متصل نیستند. در حال حاضر فقط درخواست آنها ثبت می‌شود. قدرت جاسوس هنوز جواب نمی‌دهد. همچنین فینال پنجشنبه، ریتارگت، بستن هفته، تساوی فروش، ثبت پیشنهاد خرید توسط اعضا، گزارش خصوصی عملیات و تاریخچه کامل مدیر پیاده‌سازی نشده‌اند.

**مهم امنیتی:** مسیر ثبت فروش در نسخه اولیه هنوز تراکنش واحد دیتابیسی نیست؛ در شرایط شکست بین ثبت و افزایش موجودی ممکن است نیاز به ترمیم مدیریتی داشته باشد. باید قبل از انتشار واقعی به یک RPC تراکنشی منتقل شود. نمایش آمار کلیدهای مدیر و روند تسویه هم نیازمند طراحی است.

## نصب و راه‌اندازی توسعه
1. در Supabase یک پروژه بسازید و فایل `supabase/schema.sql` را در SQL Editor اجرا کنید.
2. در Authentication > Users، یازده حساب بسازید: ده بازیکن و یک مدیر. ایمیل و رمز هر کاربر را جداگانه تعریف کنید.
3. در جدول `teams` دو تیم با نام‌های `تیم امیرعلی` و `تیم میلاد` بسازید.
4. در `profiles` برای هر کاربر، UUID دقیق حساب Auth، نام فارسی، team_id و is_admin را ثبت کنید. حساب مدیر is_admin=true و team_id=null دارد.
5. فایل `.env.example` را به `.env.local` کپی کنید و سه مقدار Supabase را وارد کنید. `SUPABASE_SERVICE_ROLE_KEY` محرمانه است و نباید در NEXT_PUBLIC یا مرورگر قرار گیرد.
6. `npm install` و سپس `npm run dev` را اجرا کنید. به http://localhost:3000 بروید.
7. برای استقرار آزمایشی، مخزن را به GitHub منتقل کنید و در Vercel با متغیرهای محیطی بالا Deploy کنید. آدرس رایگان معمولاً زیر دامنه `vercel.app` خواهد بود. هیچ آدرس واقعی تا قبل از Deploy ساخته نشده است.

## تیم‌ها
- تیم امیرعلی: امیرعلی، یاسر، یگانه، آرزو، سامان
- تیم میلاد: میلاد، ماری، نسترن، نیما، شمیم

## نکات محصول
- کلید طلایی در `weeks` محفوظ است و برای بازیکنان ارسال نمی‌شود.
- نقش‌ها و وضعیت کلیدها با سیاست‌های RLS تفکیک شده‌اند.
- یک حذف کلید به صورت **تصادفی از کلیدهای قطعاً اشتباه** انجام می‌شود. این تصمیم قابل تغییر است.
- ساعت قطع عملیات ۱۰:۰۰ به وقت تهران است. ثبت فروش روزانه نیز با تاریخ تهران انجام می‌شود.
- برای استفاده واقعی باید روز پنجشنبه و وضعیت تسویه هفته و عملیات‌ها نهایی شود.
